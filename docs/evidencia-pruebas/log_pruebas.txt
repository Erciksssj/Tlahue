CP-17 · Prueba de extremo a extremo (End-to-End) vía navegador (Playwright/Chromium)
--------------------------------------------------------------------
Escenario: una dirección municipal llena el formulario web completo (con archivo
adjunto), lo envía, recibe folio COMSOC-2026-005; consulta el folio en la vista
pública; el encargado inicia sesión en el panel, localiza la solicitud en la
columna "Recibida" y la mueve a "En diseño" con un comentario.
Verificación en base de datos tras la prueba:
  solicitud.estatus = 'En diseño'
  historial_estatus: Recibida -> En diseño con comentario y fecha correctos
Evidencia fotográfica: docs/evidencia-pruebas/screenshots/01 a 08.png
RESULTADO: APROBADA — el flujo opera de manera consistente entre frontend,
backend y base de datos, sin intervención manual en la base de datos.
